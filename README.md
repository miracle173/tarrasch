# tarrasch
Übungen von "Tarrasch, Das Schachspiel"

## Erstellen einer Übung in chess.com:
"Train"-> "Analysis" -> "Set Up Position"
"Trainieren" -> "Analyse" -> "Stellung aufbauen"
* "Clear Board"
* "Brett aufräumen" (Mistkübel)
* 
* Figuren setzen, wenn eine Figur auf einem falschen Platz gesetzt wurde, kann sie mit der richtigen Figur überschrieben werden. Wenn allerdings das Feld leer sein sollt, zieht man sie auf das richtige Feld, wenn sie ganz verschwinden soll, zieht man sie auf ein besetztes Feld und überschreibt diese Feld wieder mit der richtigen Figur
* "Weiß am Zug" oder "Schwarz am Zug" wählen
* Metadaten ausfüllen, z.B. für Diagramm Nr. 51 
* * [Event "Tarrasch, Das Schachspiel"]
  * [Round "Nr. 51"]
* falls Rochaden noch möglich, entsprechende Kästchen anklicken
* 
*  "Laden" drücken
*  "Load"
*  
*  "Speichern" drücken und geeignete Sammlung, also "Tarrasch" auswählen und "+" drücken
*  "Save"

## Analysieren
* "Mehr" "Andere" ->  "Sammlungen" -> Tab "Deine Sammlungen"
* analysieren
* "Speichern" drücken

* Stellung auswählen
* eventuell einen Zug machen
* eventuell "Swith Sides" drücken
